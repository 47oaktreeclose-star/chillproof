# ChillProof

Fridge & freezer temperature logs for UK food businesses (Flutter, Android).

- Every push to `main` builds the Google Play file (`.aab`) and a test `.apk` — see the **Actions** tab.
- Privacy policy: `docs/privacy-policy.html` (served by GitHub Pages from `/docs`).
- Settings you may change: `lib/config.dart`. Version: `pubspec.yaml`.
